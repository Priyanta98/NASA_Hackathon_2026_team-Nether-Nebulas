    1. Known-Object Recovery against IMCCE SkyBoT asteroids/Centaurs with empirical recall rate (%).
    2. Synthetic Injection Completeness Heatmap (2D grid of Velocity ["/day] vs. Surface Brightness [MJy/sr] / Distance [AU]) showing what SPHEREx can rule out.

  - **Hero 2 (Motion-Corrected LVF Spectrophotometry — `reconstruct_motion_corrected_spectrum()`)**:
    Because SPHEREx's Linear Variable Filters sample different wavelengths at different exposure times (t_i), static forced photometry smears a moving object's spectrum. Shift the extraction aperture along the moving object's predicted trajectory `(RA(t_i), Dec(t_i))` at each exposure's MJD and evaluate `WCS-WAVE` (`key="W"`, `sip=None`) to recover the un-smeared 0.75-5.0 um spectrum (highlighting 3.0 um H2O and 3.3 um CH4 ice bands).
  - **Hero 3 (Serendipity Feed, Devil's Advocate Panel & Blink Quest — `src/detection/ml_detector.py`)**:
    1. 3-Stage Hybrid Ensemble (`PSF` HDU 5 template cross-correlation + `IsolationForest` Serendipity anomaly ranker + soft-voting `HistGradientBoostingClassifier` + `RandomForestClassifier` + `ExtraTreesClassifier` pre-trained via Synthetic Source Injection).
    2. Devil's Advocate Panel quantifying falsification probabilities for 5 artifacts: Cosmic Ray, Detector Persistence (`MP_PERSIST`), Optical Ghost, High-Proper-Motion Star (Gaia DR3), and Zodiacal Light Residual.
    3. Reproducible Evidence Card with cutout thumbnail, `FLAGS` bitmask hex breakdown, catalog query UTC timestamps, and SHA-256 data hash.
    4. Blink Quest gamified human vetting feeding labels back into active-learning ensemble weights.

### 3. AUTHORITATIVE NASA/IPAC SPHEREx API, FITS & ASTROMETRIC SPECIFICATIONS
1. IRSA SIA v2 Endpoint (`https://irsa.ipac.caltech.edu/SIA`):
   - Public API (no API key required). Collections: `spherex_qr2`, `spherex_qr3`, `spherex_qr2_deep`, `spherex_qr3_deep`.
   - Query: `GET https://irsa.ipac.caltech.edu/SIA?COLLECTION=spherex_qr2&POS=circle+{ra_deg}+{dec_deg}+{radius_deg}&RESPONSEFORMAT=CSV`
   - Server-side Cutouts: Append `?center={ra_deg},{dec_deg}&size={size_deg}` to `access_url`.
   - Offline Demo Cache: Pre-populate `data/cached_demo/benchmark_epochs.json` so all features run offline if IRSA is unreachable.
2. SPHEREx Level 2 MEF 6 Extensions (~6.15 arcsec/pixel):
   - `IMAGE` (HDU 1, MJy/sr), `FLAGS` (HDU 2, 32-bit int bitmap), `VARIANCE` (HDU 3, (MJy/sr)^2), `ZODI` (HDU 4, MJy/sr — subtract `IMAGE - ZODI`), `PSF` (HDU 5, 101x101x121 cube), `WCS-WAVE` (HDU 6, `key="W"`, `sip=None`).
